# IntelliLearn Platform

IntelliLearn is an end-to-end learning management platform powered by Gemini LLM, designed for students, teachers, and parents. It features adaptive learning, AI-driven analytics, and interactive dashboards.

## Key Features

### 🚀 Adaptive Learning Rate
- Each student has a unique learning rate (1-100) that is continuously evaluated and updated based on their interactions, performance, and engagement.
- The learning rate directly influences the difficulty and conciseness of content, assessments, and study materials generated by the Gemini LLM.
- Learning rate is stored per student and per subject, and is used as a main parameter for all LLM-powered content and evaluation.

### 📚 Personalized Content & Assessment
- Course content and assessments are generated and adapted by Gemini LLM, based on the student's learning rate and chat history.
- Content becomes more concise and challenging for fast learners, and more detailed and simplified for slow learners.
- Only teacher-approved materials are delivered to students.

### 💡 AI-Powered Insights & Analytics
- Real-time analysis of student performance, focus, marks, attendance, doubts, strong/weak subjects, and overall progress.
- Teachers receive actionable insights on topics where students struggle, helping them tailor future content and interventions.
- Parents can monitor behavioral trends, doubt frequency, and interaction patterns for their children.

### 🏆 Gamification & Leaderboards
- Leaderboards and badges motivate students and foster healthy competition.
- Gamified feedback and challenges are generated by the LLM to enhance engagement.

### 🤖 ILM Chat History & Contextual Intelligence
- Each student’s ILM chat history is stored per subject and summarized using the LLM on login.
- This summary, along with the learning rate, is used as context for all subsequent LLM interactions, ensuring personalized and context-aware responses.

### 👩‍🏫 Teacher & Parent Dashboards
- Teachers manage courses, students, attendance, content approval, assignments, and communication—all with AI support.
- Parents access detailed analytics, behavioral reports, and direct messaging with teachers.

## How to Run

1. **Backend (FastAPI):**
   - Run `main.py` to start the API server.
2. **Frontend (Streamlit Dashboards):**
   - Run `streamlit run dashboard/student_dashboard.py`
   - Run `streamlit run dashboard/teacher_dashboard.py`
   - Run `streamlit run dashboard/parent_dashboard.py`
3. **Configuration:**
   - Add your Gemini API key to `config.yml`.
   - Customize prompts in `resources/prompts.py`.

## Project Structure
- `app/` - Backend API and business logic
- `dashboard/` - Streamlit dashboards for all user types
- `llm/` - LLM client integration
- `db/` - Mock database (JSON files)
- `resources/` - Prompts and configuration
